# 보안회의록 - 안드로이드 APK 만들기 (배당금캘린더와 동일한 방식)

이전에 배당금캘린더 만드셨던 것과 완전히 같은 방식(Capacitor + GitHub Actions)입니다.
이번엔 처음부터 `capacitor.config.json`(TypeScript 아님)으로 만들어서, 저번에 겪으셨던 `.ts` 오류는 애초에 생기지 않습니다.

## 이번에 추가로 고친 부분

원본 파일의 "수동 내보내기" 버튼은 원래 웹 브라우저 다운로드(`<a download>`) 방식이라, 안드로이드 앱(WebView) 안에서는 저장이 안 되거나 항상 기본 폴더로만 갔습니다.
그래서 배당금캘린더 때와 똑같이 **Capacitor의 Filesystem + Share 플러그인**을 연결해서, 앱 안에서 "수동 내보내기"를 누르면 **안드로이드의 저장 위치 선택 창(공유창)**이 뜨도록 고쳐놨습니다. 거기서 "파일에 저장"을 고르면 원하는 폴더를 직접 골라서 저장할 수 있습니다.

(참고: `showDirectoryPicker`로 폴더를 미리 "연결"해서 매번 자동 저장하는 기능 자체는 안드로이드에서 여전히 지원되지 않습니다. 대신 내보내기를 누를 때마다 저장 위치를 그때그때 고르는 방식으로 동작합니다.)

## 1단계 — GitHub에 새 저장소 만들기

1. https://github.com 우측 상단 `+` → `New repository`
2. 이름 예: `meeting-notes-app` → `Create repository`

## 2단계 — 파일 업로드 (제일 많이 틀리는 부분!)

1. 이 zip 파일을 컴퓨터에서 먼저 **압축 해제**하세요
2. 압축을 풀면 생기는 폴더를 **더블클릭해서 안으로 들어간 다음**, 그 안의 내용물(`android`, `www`, `package.json`, `capacitor.config.json` 등)을 **전체 선택**해서 업로드 화면에 끌어다 놓으세요.
   - ⚠️ 폴더 자체를 통째로 끌어다 놓지 마세요 (그러면 파일들이 한 단계 더 안쪽으로 들어가서 빌드가 실패합니다)
3. 업로드 후 **`.github` 폴더가 목록에 보이는지 꼭 확인**하세요. 점(`.`)으로 시작하는 폴더라 드래그 시 자동으로 빠지는 경우가 많습니다.
   - 안 보이면: 저장소 화면에서 **Add file → Create new file** → 파일명에 `.github/workflows/build-apk.yml` 입력 → 이 프로젝트의 같은 파일 내용을 그대로 붙여넣고 Commit
4. **Commit changes**

## 3단계 — 자동 빌드 확인

1. 저장소 상단 **Actions** 탭
2. "Build Android APK"가 3~5분 내로 초록 체크로 완료됩니다
3. 완료된 항목 클릭 → 맨 아래 **Artifacts**에서 `meeting-notes-debug-apk` 다운로드 → 압축 풀면 `app-debug.apk`

## 4단계 — 휴대폰 설치

1. `app-debug.apk`를 휴대폰으로 전송 후 설치
2. "출처를 알 수 없는 앱" 경고가 뜨면 설정에서 허용 후 재설치
3. "보안회의록" 앱 아이콘이 생깁니다 (기본 Capacitor 아이콘입니다 — 원하는 아이콘 이미지 있으면 말씀해 주세요, 배당금캘린더 때처럼 만들어 드릴 수 있습니다)

## 참고

- 데이터는 앱 내부(WebView)에 새로 쌓입니다. 기존에 PC/모바일 브라우저에서 쓰시던 데이터가 있으면, 그 화면의 "수동 파일 관리 → 내보내기"로 백업 파일을 뽑아서, 앱 설치 후 "불러오기"로 옮기시면 됩니다.
- 지금은 개인용 디버그(debug) APK입니다.
- 빌드가 실패(빨간 X)하면 저번처럼 실패한 단계를 클릭해서 나오는 에러 로그를 캡처해서 보내주세요.
